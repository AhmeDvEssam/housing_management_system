# 🏠 Housing Management System | مشروع إدارة الإسكان

> [!WARNING]
> **⚠️ Status: Under Development | قيد التطوير**
> This project is currently in the active development phase. Features and documentation are subject to change.

## 🌟 Overview | نظرة عامة
A comprehensive management system for housing projects, designed to handle memberships, payments, bookings, and inventory efficiently.

نظام متكامل لإدارة مشاريع الإسكان، مصمم للتعامل مع العضويات، المدفوعات، الحجوزات، والمخزون بكفاءة عالية.

## 🛠 Features | المميزات
- **👥 Member Management**: Track and manage project members and their profiles.
- **💳 Payment System**: Secure handling of installments and financial records.
- **📅 Booking Engine**: Manage property bookings and reservations.
- **📦 Inventory Control**: Real-time tracking of available units and assets.
- **📊 Interactive Dashboard**: Visual overview of project status and analytics.
- **📜 Audit & Reports**: Detailed logging and professional reporting tools.

## 🚀 Getting Started | البدء في الاستخدام

### Prerequisites | المتطلبات الأساسية
- **Python 3.12+**
- **PostgreSQL 16**

### Installation | التثبيت

#### Linux:
```bash
./setup_linux.sh
./run_linux.sh
```

#### Windows:
1. Run `setup_windows.bat` to initialize the environment.
2. Run `run_windows.bat` to start the server.
3. Detailed guide: [WINDOWS_DEPLOYMENT_ar.md](./WINDOWS_DEPLOYMENT_ar.md)
